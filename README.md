# emailchrono-synapse

AI review mode for emailchrono, built with Synapse CLI for the 2nd Brain Labs x Geek Room Vibe-a-thon (Track 2: one smart tool from many small functions).

Status: work in progress.

## Source of the app

`backend/` and `frontend/` start as a copy of [iris-ng/emailchrono-local](https://github.com/iris-ng/emailchrono-local) at commit `c326963` (Apache 2.0, see [LICENSE](LICENSE)). Changes made to the copy are listed in the write-up.

## Synapse-generated code

`backend/resolve_case_duplicates_server.py` is generated by Synapse CLI 0.1.9 in Custom mode (`--local`, OpenAI) from the adapters in `backend/app/review/dedupe.py`. One line is edited by hand: Synapse dropped the default on `plan_id`, so `= None` was added. Synapse's own check does not run the code, so every generated file is tested by running it as a real MCP server (`backend/tests/test_generated_servers.py`).

## Setup (macOS)

1. Python venv (3.12) and backend packages:
   ```bash
   uv venv --python 3.12 .venv
   uv pip install --python .venv/bin/python -r backend/requirements.txt pytest
   ```
2. Frontend build:
   ```bash
   (cd frontend && npm ci && npm run build)
   ```
3. Synapse CLI 0.1.9, installed locally (not global):
   ```bash
   (cd tools/synapse && npm ci)
   scripts/synapse.sh --version
   ```
4. OpenAI key: put `OPENAI_API_KEY=...` in `secrets.local` (gitignored). `scripts/synapse.sh` reads it and always sets `SYNAPSE_TELEMETRY=0`. The agent uses `gpt-5.6-luna` by default (`EMAILCHRONO_AGENT_MODEL` overrides it).
5. Demo data and app:
   ```bash
   .venv/bin/python demo_data/build.py --force   # fresh data/demo with two cases
   scripts/run_app.sh                            # http://127.0.0.1:8765
   ```

## Demo data

All demo data is fake. `demo_data/planted.py` writes the planted case (`demo_data/planted/*.eml`) and its answer key (`demo_data/ground_truth.json`). Each file targets one known gap in the parser or duplicate scorer; the `purpose` field in the answer key says which. The optional sample case reads a local folder of Gmail `.eml` files that is not part of this repo.
